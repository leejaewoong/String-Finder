# L10N Node Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Figma Target Node를 기준으로 위키 행을 안정적으로 동기화하고 누락 행을 보존하면서 모든 String ID 충돌 계산에 포함한다.

**Architecture:** Confluence Content Property에 표 행과 Figma Node의 연결 정보를 저장하고, 순수 표 동기화 함수가 현재 Figma 스캔과 기존 행을 reconciliation한다. Orchestrator는 표와 메타데이터를 함께 읽고 쓴 뒤 활성 행만 LLM/JSON 단계로 전달한다. Figma 스캐너는 Frame 전체의 내비게이션 문맥과 중복 Target을 정규화한다.

**Tech Stack:** Electron 27, React 18, TypeScript 5, Vitest, Cheerio, Confluence REST API, Figma REST API, OpenAI Chat Completions API

**Spec:** `docs/superpowers/specs/2026-09-03-l10n-node-sync-design.md`

## Global Constraints

- 영문과 사용자 비고는 Figma 동기화로 변경하지 않는다.
- `Figma 태그 누락` 상태는 비고에 기록하지 않는다.
- 유효한 Tag가 있는 Frame만 신규 처리한다.
- Git commit과 push는 수행하지 않는다.
- 기존 작업 트리의 사용자 변경을 보존하고 관련 파일만 수정한다.
